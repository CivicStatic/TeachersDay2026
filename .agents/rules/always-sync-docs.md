# Mandatory Documentation Synchronization Rule

Whenever you make any changes to the codebase (including `index.html`, `style.css`, `app.js`, CI/CD workflows, or scripts), you **MUST** update and synchronize both [`README.md`](../../README.md) and [`GEMINI.md`](../../GEMINI.md).

## Protocol
1. Follow the procedure defined in the [`sync-docs-on-change`](../skills/sync-docs-on-change/SKILL.md) skill.
2. Ensure [`README.md`](../../README.md) reflects all new features, UI controls, and usage commands.
3. Ensure [`GEMINI.md`](../../GEMINI.md) reflects all engineering specifications, CSS token declarations, mathematical physics formulas, DSP audio tables, subsystem architecture diagrams, and versioning logs.
