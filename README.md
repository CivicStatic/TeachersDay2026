# 🎓 Teachers' Day 2026 Tribute Website
> *“To the Guiding Lights: Celebrating the minds that shape our future.”*

A tribute single-page web application celebrating educators and mentors worldwide. Built with pure zero-dependency Semantic HTML5, Modern CSS3 with smooth 60fps `@keyframes` anti-gravity physics, and native ES6+ JavaScript with real-time procedural Web Audio synthesis and a High-DPI Greeting Card Studio.

---

## ✨ Key Features & Highlights

1. **Magical "Anti-Gravity" Background Physics**:
   - Small, stylized, semi-transparent SVG icons (🍎 Apple, 📖 Book, ✏️ Pencil, 🎓 Graduation Cap, 💡 Glowing Lightbulb, ⚛️ Science Atom, 🌟 Stars) ascend gently through the viewport with continuous sinusoidal lateral sway (`swayDrift` + `floatUpward`).
   - Micro-parallax responds softly to pointer movement.

2. **Opulent Academic Theme & Design Tokens**:
   - **Colors**: Deep Midnight Navy (`#060B19`, `#0B152D`), Luminous Gold (`#FFB703`, `#FFE885`, `#D4AF37`), Soft Cream (`#FFFDF8`), and Chalkboard Slate (`#1E293B`).
   - **Typography**: `Playfair Display` (Classic Elegance), `Caveat` (Handwritten warmth on sticky notes), `Plus Jakarta Sans` (Modern readability), and `Cinzel Decorative` (Regal accents).

3. **Floating Centerpiece Hero Showcase**:
   - Large welcoming banner with golden gradient typography.
   - Levitating vector illustration depicting mentorship, glowing constellations, knowledge rings, and floating books in zero gravity.
   - Dual Call-to-Action buttons: *Leave a Tribute* and *Read Wisdom*.

4. **Interactive Quote Carousel (Wisdom of Mentors)**:
   - 5 rotating quotes from Nelson Mandela, Dr. A.P.J. Abdul Kalam, Malala Yousafzai, Albert Einstein, and Carl Sagan.
   - Auto-rotation every 6.5s, hover pause, dot indicators, and keyboard/button controls.

5. **Dynamic Gratitude Wall (Masonry Pinboard)**:
   - Sticky notes with pastel & slate themes, tilt rotations, category chips, and like counters.
   - Real-time composer form with custom color swatch and pin emoji selectors.
   - **Local Storage Persistence**: Tributes are saved locally and persist across sessions.
   - **Search & Filter Engine**: Instant filter by category (*Inspiring*, *Life Changer*, *Patience*, *Mentorship*) or search keywords.

6. **Interactive Dedication Studio (Live $1200\times 800\text{ px}$ Canvas Generator)**:
   - Custom greeting card builder with theme presets (*Midnight Cosmic*, *Emerald Academy*, *Royal Parchment*).
   - One-click HD PNG export and direct WhatsApp share.

7. **Procedural Web Audio Engine**:
   - Dynamic sine and harmonic tone synthesis via native browser `AudioContext`.
   - Peaceful ambient meditation chimes and celebration arpeggios with zero audio file downloads.

8. **Confetti Celebration Engine**:
   - Physics-driven particle explosion triggered upon tribute pinning and card exports.

## 🚀 How to Run Locally

Since this project has **zero build dependencies**, you can open `index.html` directly in any modern browser:

### Option 1: Direct File
Double-click `index.html` or open it with your browser:
```bash
start index.html   # On Windows
```

### Option 2: Local HTTP Server (e.g. VS Code Live Server or Python)
```bash
python -m http.server 8000
# Open http://localhost:8000 in your browser
```
